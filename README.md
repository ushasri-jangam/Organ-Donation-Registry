# Organ Donation Registry Management System

A DBMS project developed using Python, Streamlit, and MySQL.

## Project Description

The system manages donor registrations, recipient registrations, organ availability, hospitals, coordinators, medical compatibility, and transplant records.

## Technologies Used
- Python
- Streamlit
- MySQL
- Git and GitHub

## Features
- Donor Registration
- Recipient Registration
- Donor and Recipient Records
- Organ Availability
- Hospital Details
- Coordinator Details
- Medical Compatibility
- Transplant Records
- Live Dashboard
